# Original atelier worker instructions

These instructions were authored for this repository. They implement a staged workflow; model aliases are selected by the operator/router according to availability and measured cost.

## Structure worker

Read the current asset contract and app source before changing geometry. Use the existing atelier dimensions unless an explicit dimensioned reference supersedes them. Record measured dimensions separately from assumptions. Work only in your assigned new build directory. Produce reproducible Blender Python, an editable structural source, GLB exports, an object/geometry/UV baseline digest and a machine-readable receipt. Run the missing-object and corrupt-output checks. Return actual evidence and unresolved assumptions. Do not claim a floor-plan reconstruction without its source, human approval, browser verification, a deployed result, or zero model usage. Do not change app content or other worker files.

## Material and lighting worker

Receive the accepted structural source and independently recorded baseline digest. Verify them before work. Use a separate final source. Preserve every structural object, parent, transform, vertex, polygon and UV. Change only materials and permitted scene lighting; no geometry modifiers or replacement scene. Treat any style image as palette/mood guidance, never new dimensional authority. Finish with an independent comparison against the original digest, exported GLB validation and exact artifact hashes. If preserving the contract prevents the requested style, report the conflict instead of replacing the baseline.

## Independent checker / merge worker

Check actual output bytes against the handed-off hashes and run structural verification on the final Blender source. Open the exported model in the app, test frame selection and unique artwork textures, and force a failed asset load to prove fallback. Capture browser evidence at a named viewport; report device performance as unmeasured unless actually tested. Publish only the accepted generation with an exclusive writer lock. Keep public claims, source-build results, browser results and human approval in separate receipt fields.
